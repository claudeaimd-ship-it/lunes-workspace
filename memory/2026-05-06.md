### Problemas del día
- **Transcripción de audio:** faster-whisper model small/base muy pesados para RasPi (OOM). Model tiny funciona pero transcripción es imprecisa. Alternativa: chunking o usar whisper.cpp en el futuro.
- **Túnel inestable:** localhost.run se cayó múltiples veces. Se configuró `autossh` con ServerAliveInterval=15 y un script de túnel robusto con captura automática de URL.
- **Chart.js desde CDN lento:** Se descargó localmente y se sirve desde el backend como archivo estático.
- **Backend confusión:** Había dos backends (8001 server.py y 8002 cdm_server.py). Se consolidó todo en ~/cdm-dashboard/ con server.py.

### Arquitectura final
- Service: `cdm-dashboard` (systemd, Restart=always, WorkingDirectory=~/cdm-dashboard)
- Túnel: `cdm-tunnel` (script con autossh, captura URL a tunnel_url.txt)
- Puerto 80: `cdm-port80` redirige a 8001
- Acceso público: túnel localhost.run → URL variable
